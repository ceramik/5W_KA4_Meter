- Settings: history and local-calendar statistics, estimated fuel costs, LED colors and screen dimming, speed diagnostics, toll, QR/CSV, GitHub link, optional Android boot service.
- Running trip checkpoint every 2 seconds, resumes from last saved sample, not from elapsed shutdown time. Force-stop and firmware may block boot broadcast. Completed trip history begins with v5.

Inspect stationary head unit with adb shell getprop, adb shell service list, adb shell dumpsys location, adb shell pm list packages; no CAN transmissions. Determine OEM API and permission requirements before adding bridge sender. Android BOOT_COMPLETED service is not a NEMESIS-specific launcher hook.
